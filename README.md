# AIfriend

**EN**

AIfriend is an AI friend: conversation, closeness and someone who listens. Clearly labelled as AI, with clear boundaries - a companion, not a replacement for real people.

**DE**

AIfriend ist ein KI-Freund: Unterhaltung, Nähe und jemand, der zuhört. Klar als KI gekennzeichnet, mit klaren Grenzen - ein Begleiter, kein Ersatz für echte Menschen.
